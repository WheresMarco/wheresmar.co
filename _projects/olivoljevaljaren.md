Zeta ville ha en webbplats som presenterade deras olivoljor på ett tydligt sätt. Olivoljeväljaren är byggd i React.

Tjänsten är uppdelad i kategorier efter vad olivoljan ska användas till, till exempel bakning eller matlagning. Det går också att justera smakstyrkan för att hitta rätt intensitet.

Datan hämtas via WordPress REST API från materialdatabasen som byggdes åt Zeta, och hela tjänsten går att köra på enkel webbhosting eller lokalt.
